# Data Analyst & Power Platform Developer Portfolio

A premium, production-ready portfolio website built with React, Vite, Tailwind CSS, and Framer Motion.

## Features

- 🎨 Modern dark theme with glassmorphism effects
- ✨ Smooth animations and scroll-triggered reveals
- 📱 Fully responsive design
- 🚀 Optimized performance with lazy loading
- 📊 Interactive project modals with detailed information
- 📝 Contact form with validation
- 🎯 SEO optimized meta tags
- ⚡ Page loading animation

## Tech Stack

- React.js 18
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React Icons
